# TURAN.İ.O MMC

TURAN.İ.O MMC — 2019-cu ildən tikinti və təmir sahəsində fəaliyyət göstərən şirkət üçün hazırlanmış korporativ veb-sayt layihəsi.

## Fəaliyyət istiqamətləri

- Yaşayış binalarının tikintisi
- Qeyri-yaşayış obyektlərinin tikintisi
- Cari və əsaslı təmir işləri
- Kommunal kommunikasiya işləri
- Layihə idarəetməsi və sahə nəzarəti

## Texnologiya

- Next.js
- React
- CSS Modules / plain CSS

## İşə salmaq

```bash
npm install
npm run dev
```

Sayt lokalda `http://localhost:3000` ünvanında açılacaq.
